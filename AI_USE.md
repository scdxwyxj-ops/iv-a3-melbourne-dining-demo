# AI Use Statement

**Updated:** 27 October 2026 · GEOM90007 Assignment 3 · Group 26

This statement documents the scope of AI assistance used during the project.

## Tool and Scope

OpenAI ChatGPT assisted with the following tasks during October 2026:

| Area | Recorded assistance |
| --- | --- |
| Task analysis and planning | Analysing assignment requirements, breaking down project tasks, identifying key objectives and providing recommendations on implementation approaches. |
| Dataset research and evaluation | Searching for relevant datasets, evaluating their suitability, quality and limitations, and providing recommendations on dataset selection and potential applications. |
| Demo generation and comparison | Generating frontend prototypes and demonstration examples for internal team evaluation, facilitating comparisons of alternative UI designs and supporting the selection of the most suitable approach. |
| Automated testing and code review | Assisting with automated testing of code uploaded to GitHub, identifying potential issues and conducting AI-assisted code reviews before merging pull requests. |
| Layout guidance and course review | Providing suggestions on formatting, visual layout and interface organisation, as well as reviewing relevant concepts from course materials to support project development. |

## Contribution and Acknowledgement

AI assistance supported project development, evaluation and team discussions. Final implementation decisions and submitted deliverables remained the responsibility of the team.

Individual contributions are documented through the project's GitHub history.
