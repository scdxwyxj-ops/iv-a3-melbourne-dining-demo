# 公共设计语言

四个页面沿用设计 Demo 中的浅底色与白色卡片。控件放在左侧，中间用于地图，右侧显示摘要或结果。所有页面共用 `www/css/common.css`，功能自己的调整放在对应 CSS 文件。

## 颜色

| CSS token | 色值 | 用途 |
|---|---|---|
| `--color-primary` | `#087f80` | 主操作、咖啡馆与餐厅、比较 A |
| `--color-secondary` | `#7961b0` | 比较 B 与重叠说明 |
| `--color-takeaway` | `#db8950` | 外卖类别的标记 |
| `--color-text` | `#203b36` | 正文与标题 |
| `--color-muted` | `#657970` | 辅助说明 |
| `--color-background` | `#f6f8f6` | 页面背景 |
| `--color-surface` | `#ffffff` | 卡片背景 |
| `--color-border` | `#dce6e0` | 卡片和控件边框 |

类别色必须在四页一致。比较中的 A/B 同时显示文字标签，不能只靠颜色区分。橙色先用于类别标记，正文和按钮仍使用公共文字色与主色。

## 字体与布局

字体使用 Arial 与系统 sans-serif。页面标题 25px，卡片标题 15px，正文默认 14px，说明文字 12px。指标数字默认 42px；比较双列卡片为 34px。

卡片圆角 12px，控件圆角 7px，卡片间距 16px，内边距 20px。桌面布局的控件栏宽 235px，摘要栏宽 310px，中间地图自适应。较窄窗口会折叠为两列或单列。

## 公共组件

| 组件 | 内容约定 |
|---|---|
| `feature_heading()` | 页面任务标题、简短描述、占位状态和负责人 |
| `panel_card()` | 单一用途的卡片，卡片标题使用 h2 |
| `placeholder_canvas()` | 明确标记待实现区域，不绘制虚构地图或数据点 |
| `metric_card()` | 数字、单位或对象、必要的口径说明 |
| `category_legend()` | 固定的两类餐饮图例 |
| `next_step_note()` | 占位版的开发提示；正式用户界面应移除 |

## 数据和交互文字

界面使用英文，协作文档使用中文。每页只有一个明确的主要任务，控件标签始终显示。

- 场所数量使用清洗后的一店一行记录，不能数座位行或坐标点。
- 半径单位使用 metres，距离描述为 straight-line，不能写成 walking distance。
- 座位缺失显示 Unknown；只有数据实际为 0 才显示 0。
- 零结果显示明确的空状态，让用户调整景点或范围。
- 占位版未完成的按钮禁用，并说明 coming next；不得点击后假装保存成功。
- 店名和地址作为普通文本输出，避免把源数据直接拼进未经转义的 HTML。

比较图表必须共享类别顺序和刻度，数量不描述为密度。地图后续实现需有图例，并说明调查年份；同坐标的场所不能被误认为一家店。
