# 区域概览的 Tableau 接入

功能 1 预留一个各 CLUE 区域餐饮数量比较图表。当前 `R/core/tableau.R` 只显示占位区，尚未嵌入真实 Tableau 图表，仓库没有工作簿。

制作图表时直接连接 `data/venues.csv`。按 `area` 汇总，场所数量使用 `COUNTD(venue_id)`；不能使用原始座位行数，也不能把数量标为密度。类别字段使用 `category`。

将团队自己的工作簿保存在此目录。最终按课程 8.5 的 Tableau 嵌入方法接入 Shiny，记录工作簿来源和发布 URL。若采用 Tableau Public，发布内容会公开；本目录的数据按 CC BY 4.0 使用，应保留来源与转换说明。

至少一个真实 Tableau 可视化是作业要求，四个页面不必全部使用 Tableau。接入后需检查浏览器中的加载、尺寸及筛选联动；没有真实工作簿前，不把占位图表算作已完成集成。
